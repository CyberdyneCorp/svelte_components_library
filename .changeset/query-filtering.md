Add query filtering: a typed flat query model with `operatorsFor`, `isConditionComplete`, `describeCondition` and a client-side `evaluateQuery`, plus `QueryBuilder` (field, operator and typed value rows with an all/any combinator), `FilterChipRow` (removable chips for the active conditions) and `SavedViews` (pick, save, update, rename and delete named views; storage stays in the application). See `guides/query-filtering.md`.
